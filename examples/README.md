# Examples

These examples demonstrate the main features of GLVM and how to use them.

| Example | Run Command | Description |
|-----|-----|-------|
| Hello World | `cmake --build --preset debug -t run_hello_world` | Minimal scene: debug overlay plus a white rectangle spinning around its own axis in the center of the screen. Shows base engine components in GLVM |
| TPS | `cmake --build --preset debug -t run_tps` | Demo scene with player, enemies, lights and inventory. Shows basic building blocks in GLVM |
